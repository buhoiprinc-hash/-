# Анализ успеваемости

Лабораторная работа №2 по JavaScript и Git. Программа анализирует оценки заданной группы и выводит средний балл, лучшего студента, список не сдавших и оценки по буквенной шкале.

## Запуск

Требуется Node.js 18 или новее.

```sh
node main.js
```

Либо:

```sh
npm start
```

Запуск проверок:

```sh
npm test
```

## Результат

Для исходных данных программа выводит средний балл `77.6`, лучшего студента `Денис`, список не сдавших `Студент_X` и массив оценок: Макар — B, Денис — A, Анна — B, Даша — B, Студент_X — C.

## Состав проекта

- `main.js` — исходные оценки, четыре функции обработки и демонстрационный вывод.
- `test/main.test.js` — проверки функций на заданных и граничных данных.
- `package.json` — команды `npm start` и `npm test`.

Функции экспортируются из `main.js`, поэтому их можно отдельно подключить в другом JavaScript-файле. Запуск `node main.js` формирует отчёт; импорт файла не запускает вывод автоматически.

## Как отправить преподавателю через GitHub Desktop

1. Войдите в GitHub Desktop под своим аккаунтом.
2. Выберите **File → Add Local Repository** и укажите папку этого проекта.
3. В левой панели проверьте список изменений. В поле **Summary** укажите `Complete grade analysis lab` и нажмите **Commit to main**.
4. Нажмите **Publish repository**, выберите имя и владельца репозитория, а также видимость. Публичный репозиторий преподаватель сможет открыть по ссылке; для закрытого нужно отдельно выдать ему доступ.
5. После публикации нажмите **Push origin**, если приложение предложит отправить новые коммиты. Откройте репозиторий на GitHub и убедитесь, что в `main` находятся `main.js`, `package.json`, папка `test` и этот `README.md`.
6. Отправьте преподавателю ссылку на репозиторий.

Если используете терминал вместо GitHub Desktop, добавьте эти файлы в коммит и отправьте ветку `main` на GitHub-командой `git push -u origin main`. URL `origin` должен указывать на ваш репозиторий.
