# Анализ успеваемости

Лабораторная работа №2 по JavaScript и Git. Программа анализирует оценки заданной группы и выводит средний балл, лучшего студента, список не сдавших и оценки по буквенной шкале.

## Запуск

Требуется Node.js 18 или новее.

```sh
node main.js
```

Либо:

```sh
npm start
```

Запуск проверок:

```sh
npm test
```

## Результат

Для исходных данных программа выводит средний балл `77.6`, лучшего студента `Денис`, список не сдавших `Студент_X` и массив оценок: Макар — B, Денис — A, Анна — B, Даша — B, Студент_X — C.

## Состав проекта

- `main.js` — исходные оценки, четыре функции обработки и демонстрационный вывод.
- `test/main.test.js` — проверки функций на заданных и граничных данных.
- `package.json` — команды `npm start` и `npm test`.

Функции экспортируются из `main.js`, поэтому их можно отдельно подключить в другом JavaScript-файле. Запуск `node main.js` формирует отчёт; импорт файла не запускает вывод автоматически.
